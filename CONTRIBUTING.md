# Contributing Guidelines

Thank you for considering contributing to this project!

## Reporting Issues
- **Search existing issues** before opening a new one.
- For bugs, include **steps to reproduce, expected behavior, and actual behavior.**
- For feature requests, describe the **use case** and why it adds value.
- GitHub Issues: https://github.com/blue-wind-25/JxMake/issues  
- SourceForge tickets: https://sourceforge.net/p/jxmake/tickets — please use GitHub Issues first, if possible.  

## Making Changes
- **Fork the repository** and create a descriptively named branch  
  *(e.g. `fix/usb-reset-hang`, `feat/cyw43-deinit`)*.
- **Follow the existing coding style and conventions.**
- **Keep changes focused** — one concern per pull request.
- Write **clear, descriptive commit messages.**

## Submitting a Pull Request
- **Describe what your PR changes and why.**
- Reference any related issue *(e.g. `Closes #42`)*.
- Ensure your changes **don’t break existing functionality.**
- A maintainer will review and may request changes before merging.

> **Note:** Pull Requests and Issue Templates are **GitHub‑only features.**  
> On SourceForge, please use the **ticket system** for bug reports and feature requests.  
> Code contributions on SourceForge are typically handled via patches or direct commits.

## Code of Conduct
All contributors are expected to follow the [**Code of Conduct**](CODE_OF_CONDUCT.md).

## Disclaimer
These guidelines are **community guidance, not a legal contract.**  
They do not override GitHub or SourceForge terms of service.  
Maintainers may interpret and enforce them within the scope of this project.
