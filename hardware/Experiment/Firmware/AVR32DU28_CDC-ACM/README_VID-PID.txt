====================================================================================================
USB Vendor and Product IDs
====================================================================================================

The firmware source code in this directory uses the VID and PID from 'Microchip Technology, Inc.
CDC RS-232 Emulation Demo' (0x04D8 and 0x000A).

While this is acceptable for private use or limited distribution, commercial or public reuse of
these VID and PID values may be prohibited by USB-IF, even if the firmware is technically derived
from the Microchip example and SDK.

Please edit 'MCC_AVRDU_USB_CDC_ACM/usb_descriptors.c' and replace them with your own VID and PID
as required.

====================================================================================================
