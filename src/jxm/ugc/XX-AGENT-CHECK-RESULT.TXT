NOTE: _dfuGetTransferSize() calls _getDescriptorOffset(), which returns -1 when the
  descriptor is not found. If offset == -1, the read accesses descriptor[4] and

CONTENT:             return _is.available();
SUSPECTED ISSUE: NullPointerException
NOTE: bytesAvailable(), readBytes(), writeBytes(), and flushIOBuffers() all access
  _is or _os without null checks. These are only safe to call after openPort()
  succeeds. If called before openPort() or after a failed openPort(), a NPE
  results. The pattern appears consistent with other SerialDevice implementations
  (SerialDevice_Serial, SerialDevice_JxMakeUSBGPIO) and these methods are
  presumably only called on an open port, so no change was made. If defensive
  null checks are desired, they should be added to all four methods.
