# formatter/ — working rules

Before doing any work in this directory, read `STATE.md` first. It is the
authoritative source for progress, the implementation protocol, and the
"Resolved Design Decisions" table — it supersedes general guesswork.

After any `/compact` or context summarization, re-read `STATE.md` in full
before continuing. A summary of prior conversation may omit or compress
details (exact resolved decisions, exact checklist state) that only
`STATE.md`'s current on-disk content can be trusted to have right.
