Do not execute `make test`. This and similar construct:

    switch (code) {
        case 1:
            return "one";
        case 2:
            return "two";
        case 3:
        case 4:
            return "three-or-four";
        default:
            return "unknown";
    }

must be reformatted as:

    switch(code) {

        case 1  : return "one"          ;
        case 2  : return "two"          ;
        case 3  : /* FALL-THROUGH */
        case 4  : return "three-or-four";
        default : return "unknown"      ;

    } // switch

currentlty the formatter produce INCORRECT result:

        switch(code) {
            case 1  : return "one"          ;
            case 2  : return "two"          ;
            case 3 : /* FALL-THROUGH */
            case 4  : return "three-or-four";
            default : return "unknown"      ;
        } // switch

In `case 3` there is not enough padding space. See `## 13. `switch` Formatting` in `STYLE.md`
