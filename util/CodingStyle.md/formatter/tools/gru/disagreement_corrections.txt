# tools/gru/disagreement_corrections.txt -- hand-verified label corrections for
# sample_default.txt, committed (same named exception to RDD_EXT_19 as
# sample_default.txt/code-formatter-ai-assist-weights.json -- traceable
# MIT/Apache-2.0/BSD-3-Clause provenance, short quoted excerpts).
#
# Populated by the "LLM-assisted disagreement sampling against
# sample_default.txt" process (STATE_AI.md open item, design agreed
# 2026-07-30): pull a stratified sample of sample_default.txt's rows, label
# them independently with an LLM without showing the existing auto-label,
# diff against the existing label, hand-verify only the disagreements, and
# append here ONLY the ones a human confirmed correct. Never append an
# unverified LLM label.
#
# Schema: same RDD_EXT_20/21 4-column format as sample_default.txt --
# <lang>\t<label:YES|NO>\t<targetWordIndex>\t<escaped-comment-text> -- each
# row's <lang>/<targetWordIndex>/<escaped-comment-text> must match verbatim
# the sample_default.txt row it's correcting (same comment text, same
# target-word index), differing only in <label>.
#
# `make gru-acquire-corpus` applies these on every run via
# apply_disagreement_corrections.py, AFTER regenerating sample_default.txt
# from scratch: any sample_default.txt row whose <lang>/<targetWordIndex>/
# <escaped-comment-text> matches a row here is dropped, and this file's
# (corrected) row is kept instead -- so a correction survives regeneration
# instead of being silently overwritten by the next auto-labeling pass. Do
# not hand-edit sample_default.txt directly to "fix" a label; add the
# correction here instead.
#
# 2026-08-04: first (and so far only) batch, a 300-row stratified sample (150
# unique-text YES + 150 unique-text NO, random.Random(42)) labeled blind by
# grok-4.3 (xAI Grok CLI, headless/-p mode); 44 confirmed corrections landed
# here and were folded into a production retrain. That retrain was reverted
# (see STATE_AI.md's 2026-08-04 entries) pending a real corpus-level CV;
# the CM5 gru-cv-corpus run resolved that question against the corpus
# WITHOUT these corrections (99.33% mean held-out precision at
# abstainThreshold=0.7) -- so this file was emptied back to its pre-Grok
# state. The 44-row batch is preserved verbatim, not lost, at
# tools/gru/unused/disagreement_corrections.2026-08-04-grok.txt for
# reference/possible future revisit; this file and the mechanism itself stay
# live for any future correction pass (Grok-sourced or otherwise) --
# apply_disagreement_corrections.py is a no-op on this file's current (0
# data rows) content, same as before 2026-08-04.
