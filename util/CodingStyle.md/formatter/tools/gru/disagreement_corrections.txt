# <lang>\t<label:YES|NO>\t<targetWordIndex>\t<escaped-comment-text> -- each
# row's <lang>/<targetWordIndex>/<escaped-comment-text> must match verbatim

# target-word index), differing only in <label>.
#
# `make gru-acquire-corpus` applies these on every run via
# apply_disagreement_corrections.py, AFTER regenerating sample_default.txt
# from scratch: any sample_default.txt row whose <lang>/<targetWordIndex>/
# <escaped-comment-text> matches a row here is dropped, and this file's
# (corrected) row is kept instead -- so a correction survives regeneration
# instead of being silently overwritten by the next auto-labeling pass. Do
# not hand-edit sample_default.txt directly to "fix" a label; add the
# correction here instead.
