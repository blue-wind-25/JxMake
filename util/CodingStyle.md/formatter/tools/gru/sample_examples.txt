# PLACEHOLDER labeled-examples file for GruTrainer -- NOT real training data.
#
# GruTrainer now has a real training loop (forward pass, backprop-through-time,
# Adam, early stopping on a validation split) -- see its class javadoc. This
# file exists only to give `make gru-train` a small, always-available input so
# that target keeps working end to end; the actual production run trains
# against the real Pool A/Pool B corpora, which per RDD_EXT_19 live only under
# /tmp/the session scratchpad and are never committed here.
#
# Schema (RDD_EXT_20 + RDD_EXT_21): one example per line, tab-separated --
#   <lang>\t<label:YES|NO>\t<targetWordIndex>\t<escaped-comment-text>
# label is binary ground truth (ABSTAIN is the GRU's own below-threshold
# runtime behavior, never a training class -- RDD_EXT_20). targetWordIndex is
# the 0-based index, after GruClassifier.tokenize, of the ambiguous word the
# label is about: the leading keyword for Pool A (keyword-ambiguity) examples,
# the last token for Pool B (period-ambiguity) examples (RDD_EXT_21). Comment
# text has literal newlines/tabs escaped as \n/\t, mirroring
# extract_comments.py's own escaping.
#
# Illustrative shapes only (not real extracted text, not licensed from
# anywhere) -- a few Pool A (keyword-ambiguity) examples, short comments
# leading with a keyword with/without enough context:
